# RiskLens AI — Python dependencies
# Tested on Python 3.14.2 / Windows (amd64)
# All packages have prebuilt cp314 wheels on PyPI — no source builds required.
#
# IMPORTANT: The original pins (scikit-learn==1.4.2, numpy==1.26.4, scipy==1.13.0,
# pandas==2.2.2, imbalanced-learn==0.12.2) were written before Python 3.14 existed.
# None of those versions have cp314 wheels. pip falls back to source builds, which
# fail because scikit-learn 1.4.x's build system requires numpy==2.0.0rc1 (a
# pre-release that does not exist on PyPI).
#
# All version changes below are minimum-bump upgrades to the first release that
# ships a cp314-cp314-win_amd64 wheel and is mutually compatible.
